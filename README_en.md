---

Multidownloader is an Utility program for recording SOOP Streams. 

- Record a stream in Real-Time, Original Quality.
- Activate checking for streams you don't want to miss. Program will automatically start recording when the stream is live.
- Default checking interval is 10 seconds. Change 'Refresh Interval' from Advanced options if you want faster response.

- If Connection is lost, program will wait for 30 seconds until finishing recording.  
     Change "Download Timeout" for your purpose (Max. 5mins.)
